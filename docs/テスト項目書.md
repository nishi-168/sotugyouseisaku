## 9. データ整合性・非機能項目

| No | 項目 | 確認内容 |
|---|---|---|
| 9-1 | 参加人数の整合性 | `_count.participations`が、実際のParticipationレコード数と一致しているか |
| 9-2 | 主催回数・参加回数の整合性 | イベント作成・参加のたびに`hostedCount`/`participationCount`が正しく加算されているか |
| 9-3 | トランザクションの担保(参加) | 参加登録処理の途中でエラーが発生した場合、Participation作成とカウント更新の両方が取り消されるか |
| 9-4 | Cookie削除後の状態 | ログアウト後、保護されたページ(`/account`等)にアクセスするとログイン画面に遷移するか |
| 9-5 | 存在しないユーザーIDへのアクセス | `/users/99999`のような存在しないIDにアクセスした場合、404が表示されるか |

## テスト実施時の注意事項

- シードデータ(`prisma/seed.ts`)を実行し直すことで、テスト環境を初期状態に戻せる
- 複数ユーザーでの動作確認が必要な項目(主催者/参加者の切り替えなど)は、Cookieを削除し別ユーザーでログインし直すことで検証する
- 日付に関するテスト(締切間近、期限切れなど)は、システムの現在日時とシードデータの日付の関係に注意する
