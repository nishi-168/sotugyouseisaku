

# イベント一覧ページ（仮）

## 調査・学習した内容

### Prismaのincludeの使い方

休んでいた時の範囲だったのでわからなかった部分を調べた。

### Prisma Clientを使い回すためのシングルトンの接続方法

最初AIに教えてもらった方法はパスを何回も通す方法だったのでエラーになっていたが、lib/prismaを通してシングルトンにしていたことを思い出して解決した。

### Prismaのスキーマ変更時の更新方法

スキーマ修正 → migrate（テーブル構造変更時） → generate（型の情報の更新）という一連の操作が必要なこと。

### seed更新方法

seedを変更したときは、以下のコマンドでseedを再実行する必要がある。

```bash
pnpm prisma db seed
```

## 悩み・疑問・課題

* Prismaの新しいバージョンでの接続方法が違うらしい
* Prismaの_countはまだよくわかっていない

## 設計

* イベント一覧にはDBに登録されているデータを全て表示させる
* 参加人数はテーブルに値を持たせず計算することにした

## 仕様

* **表示項目**：場所、カテゴリ名、主催者名、参加人数（現在数/募集人数）
* **並び順**：イベント作成日時の降順（新着順）
* **データ取得方法**：PrismaのfindManyにinclude（カテゴリ・主催者）と_count（参加人数集計）を指定して1回のクエリで取得
